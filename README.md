# 제주 역사문화 스탬프 투어

제주특별자치도 **제주역사문화 일반정보 · 위치정보** 공공데이터(120곳)로 만든 웹사이트입니다.
장소를 검색하고, 지도에서 확인하고, 나만의 답사 코스를 만들고, 방문한 곳에 스탬프를 찍을 수 있습니다.

## 화면 구성

페이지는 **1개**(`index.html`)이고, 위에서 아래로 7개 영역이 있으며 팝업이 1개 더 있습니다.

| 순서 | 영역 | 보여 주는 것 |
|---|---|---|
| 1 | 머리글 | 사이트 제목과 한 줄 설명 |
| 2 | 상태 표시줄 | "불러오는 중" → API 성공(초록) 또는 **연습 모드**(노랑, 1단계 파일 데이터 사용) |
| 3 | 검색 + 분류 칩 | 장소명·주소·제목·내용 검색, 분류별 필터, 결과 건수 |
| 4 | 지도 | 장소 핀(검색·필터와 연동). 핀을 누르면 설명 말풍선, 찜·스탬프 버튼 |
| 5 | 나만의 답사 코스 | 찜한 곳을 순서대로 지도에 선으로 연결, 순서 변경(▲▼)·삭제, 직선거리 합계 |
| 6 | 나의 스탬프북 | 방문 수와 진행 막대, 등급, 지역·분류별 진행도, 120칸 스탬프 판 |
| 7 | 장소 카드 목록 | 장소별 카드(분류, 장소명, 제목, 주소, 설명 일부), 찜·스탬프 버튼 |
| - | 상세 팝업 | 카드·핀·스탬프 칸을 누르면 전체 설명, 저작자, 주소, 좌표, 출처, 원문 링크 |

## 데이터 흐름

```
브라우저(index.html)
   ├─ GET /api/info      → api/info.js     → 공공데이터포털 일반정보 API   (JEJU_CULTURE_INFO_KEY)
   └─ GET /api/location  → api/location.js → 공공데이터포털 위치정보 API   (JEJU_CULTURE_LOCATION_KEY)
```

- API 키는 서버 함수(`api/`)에서만 환경변수로 읽습니다. 브라우저와 GitHub에는 나가지 않습니다.
- 두 응답을 **데이터 고유번호**로 합쳐 화면에 씁니다.
- API 호출이 실패하면 `index.html`에 들어 있는 1단계 파일 데이터로 보여 주고 **연습 모드**라고 표시합니다. 한쪽만 실패하면 "연습 모드(일부)"로 표시합니다.
- 찜 목록과 스탬프는 브라우저(localStorage)에 저장됩니다.

## 폴더 구성

```
index.html        화면 전체 (+ 연습 모드용 1단계 파일 데이터 내장)
api/info.js       일반정보 API 중계
api/location.js   위치정보 API 중계
api/_odcloud.js   두 API가 함께 쓰는 호출 코드
dev-server.js     로컬 테스트용 서버
.env.example      환경변수 이름 (값은 비어 있음)
.gitignore        .env.local 제외
```

## 실행 방법

1. `.env.example`을 참고해 `.env.local`을 만들고 키를 넣습니다. (파일은 GitHub에 올라가지 않습니다.)
   ```
   JEJU_CULTURE_INFO_KEY=
   JEJU_CULTURE_LOCATION_KEY=
   ```
2. 터미널에서 실행하고 `http://localhost:3000`을 엽니다.
   ```
   node dev-server.js
   ```
3. 배포(Vercel)에서는 같은 이름의 환경변수 2개를 Vercel 설정에 입력합니다.

## 사용자 관점 개선 제안 (10가지)

처음 쓰는 사용자 입장에서 살펴보고 받은 제안입니다.

1. **안내 문구 추가** — 찜·스탬프·코스가 무엇인지 설명이 없음 → 상단에 3단계 사용 안내(닫기 가능)
2. **검색 결과 없음 표시** — 결과가 없으면 빈 화면과 "0건"만 보임 → 안내 문구와 "필터 초기화" 버튼
3. **카드 목록 나눠 보기** — 카드 120장이 한꺼번에 이어짐 → 12장씩 보여 주고 "더 보기"
4. **지역 필터(제주시/서귀포시)** — 분류 칩만 있어 지역으로 좁힐 수 없음 → 주소 기준 지역 칩 추가
5. **정렬과 내 위치 가까운 순** — 목록이 데이터 번호 순 → 이름순·분류순·가까운 순 정렬 (위치 거부해도 다른 정렬은 사용 가능)
6. **상세 팝업 읽기 쉽게** — 긴 한 덩어리 글, 닫기 방법이 적음 → 문단 나누기, `Esc`로 닫기, 지도에서 보기 버튼
7. **스탬프 실수 방지** — 스탬프 취소·코스 비우기에 확인이 없음 → 확인 문구 추가
8. **스탬프 칸 설명** — 스탬프북의 "?" 칸이 무슨 뜻인지 모름 → 마우스를 올리면 분류 힌트 표시
9. **코스 저장·공유** — 코스가 이 브라우저에만 남음 → 링크 또는 텍스트로 복사하는 버튼
10. **모바일 화면 다듬기** — 지도 높이가 고정이고 버튼이 작음 → 지도 높이 조절, 버튼 키우기

## 고치고 추가한 것

위 개선 제안 중 1~4번을 적용했습니다.

| 제안 | 적용 내용 |
|---|---|
| 1. 안내 문구 | 상단에 3단계 사용 안내 추가. "닫기"를 누르면 다음부터 보이지 않음 |
| 2. 검색 결과 없음 | 결과가 없으면 안내 문구와 "필터 초기화" 버튼 표시 (검색어·분류·지역 모두 초기화) |
| 3. 더 보기 | 카드를 12장씩 표시, "더 보기 (12장 더 · 남은 N곳)" 버튼. 검색·필터를 바꾸면 처음 12장으로 돌아감. 지도 핀은 결과 전체를 표시 |
| 4. 지역 필터 | 분류 칩 아래에 전체 지역 / 제주시 / 서귀포시 칩 추가. 분류·검색과 함께 적용되고 지도 핀도 같이 걸러짐 |
